# 九枢回归铁律

## 铁律

1. **改动后必须全绿**：任何提交前，`python3 -m unittest discover -s tests -t .` 必须全绿（干净 venv 纯标准库可跑，不依赖 mcp）。
2. **红例不掩盖**：发现红例先修根因，不允许跳过、删除或放宽断言来换绿。
3. **破口即用例**：每次自攻坐实的破口（竞态、越权、契约缺口），必须沉淀为回归用例再收口。
4. **环境受限不算红**：fork 并发等沙箱受限路径不在本套件内，由内嵌 selftest（九枢长任务 `_selftest`）在具备条件的环境覆盖。
